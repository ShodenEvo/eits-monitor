# Roadmap

## v0.3 alpha — current

- Docker server deployment
- Native Windows and Linux agents
- CPU, memory, disk, uptime, and network metrics
- TCP and UDP checks
- Responsive dashboard
- Device enrollment and unique credentials

## v0.4

- Process monitoring
- Windows Service monitoring
- systemd service monitoring
- Docker container monitoring
- Persistent alert lifecycle

## v0.5

- Email and webhook notifications
- Alert acknowledgement and recovery history
- Maintenance mode
- Device groups
- Threshold inheritance

## v0.6

- Agent update workflow
- HTTP/HTTPS probes
- TLS certificate expiry checks
- DNS, NTP, and SNMP protocol probes
- Metric retention rollups

## v1.0

- Stable migration framework
- Upgrade compatibility policy
- Backup and restore tooling
- Hardened authentication and external identity integration
- External security review
- Complete administrator and operator documentation
